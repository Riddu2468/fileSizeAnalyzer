# Python File Analyzer

A beginner-friendly Python project that analyzes files in a folder.

## Features
- Lists all files in a folder
- Displays the size of each file
- Calculates the total folder size
- Shows the total size in bytes and MB

## Technologies Used
- Python
- os module

## How to Run

```bash
python file-analyzer.py
```

Enter the folder path when prompted.

## Example Output

```
example.txt
1024

image.png
204800

Total Size: 205824 bytes
0.20 MB
```
